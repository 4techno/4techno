## About

Full stack developer focused on building AI-powered applications. I work with Python and JavaScript across the stack, and I am currently exploring large language models and agentic systems.

I write code that ships. My current focus is integrating LLMs into real products using Gemini, Claude, and open-source models.

**What I am working on**

- AI chat assistant using Gemini and Claude APIs
- Personal portfolio with live project demos
- Python automation tools for everyday workflows
